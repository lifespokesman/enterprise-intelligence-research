# Industry Cases｜产业案例

本目录保存**基于公开来源、可公开讨论的企业 AI / Human-AI 组织实践案例**。

目标不是收集“某公司用了什么模型”，而是回答：现实企业中，AI 进入以后，组织关系到底发生了什么变化？

建议每个案例至少回答：

1. **Organization / Context**：组织与业务背景是什么？
2. **Scenario**：AI 进入哪个具体任务或业务链？
3. **Before / After**：AI 进入前后的工作结构分别是什么？
4. **AI Role**：AI 是信息助手、建议者、决策参与者、执行者，还是持续运行主体？
5. **Human Role**：人的角色、决策权、审核权、例外处理和责任是否变化？
6. **Coordination**：Human、Agent、Software、Data、Asset 如何协调？
7. **Outcome**：公开资料报告了什么结果？是效率、质量、成本、风险还是组织变化？
8. **Boundary**：有哪些前提、失败、限制或尚未验证的部分？
9. **Q1–Q5 Mapping**：案例主要回应哪些长期问题？
10. **Evidence Quality**：来源是公司官方案例、客户公开演讲、独立媒体、论文还是第三方研究？

## 证据纪律

- 厂商官网客户案例应标记为 **vendor-reported case**，不能自动视为独立验证；
- 宣传指标要尽量保留原始口径和来源，不自行补齐缺失的因果关系；
- 案例成功不代表机制可普遍复制；
- 公开案例如果缺少组织过程，只能记录“结果事实”，不要虚构 Human-AI 分工细节；
- 真实客户现场观察不直接放入这里，先在私有研究环境中脱敏、抽象。

## 推荐文件名

`CASE-<company-or-domain>-<topic>.md`

例如：

`CASE-enterprise-agent-decision-rights.md`

具体案例在真正进入当前 Active Question 时再建立，不为扩目录而批量收集。
