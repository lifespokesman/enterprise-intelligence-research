# VSM × AI Organization｜研究专题

> 状态：Exploring
>
> 研究问题编号：RQ-VSM-01
>
> 当前目的：验证 Stafford Beer 的 Viable System Model（VSM）能否成为 Human-Agent 混合企业的一种组织元模型或理论骨架，而不是先假定它就是答案。

## 1. 为什么现在重新研究 VSM

当前研究已经从“Agent 怎么进入企业”上移到“企业到底需要什么智能、AI 作为非人类主体后组织如何重构”。

VSM 值得重新进入视野，主要不是因为它“早就预测了 AI”，而是因为它从控制论、复杂性与组织可行性出发，重点研究：

- 多个自治单元如何协调；
- 局部自治与整体控制如何平衡；
- 组织如何感知环境并适应变化；
- 如何通过反馈维持长期可行性；
- 为什么组织结构具有递归性。

这些问题与 Human-Agent、多 Agent、企业智能、动态能力组织高度相关。

## 2. VSM 的基础结构（待精读校准）

当前先保留最小理解，不替代原著阅读：

- **System 1｜Operations**：真正承担核心业务活动的自治运行单元；
- **System 2｜Coordination**：协调多个 S1，抑制冲突与振荡；
- **System 3｜Control**：关注内部资源配置、运行优化与整体协同；
- **System 3*｜Audit / Monitoring**：获得对运行现实的补充检查与直接信息；
- **System 4｜Intelligence**：面向外部环境与未来变化，支持适应；
- **System 5｜Policy / Identity**：维持整体身份、价值、方向与政策平衡。

此外重点关注：

- **Recursion｜递归性**：一个可行系统中的运行单元本身也可能是可行系统；
- **Requisite Variety｜必要多样性**：组织必须具备足以吸收/调节环境复杂性的内部调节能力；
- **Autonomy vs. Cohesion｜自治与整体一致性**。

## 3. 与“企业智能”当前框架的候选映射

> 以下只是候选映射，不作为结论。

| VSM 功能 | 当前企业智能框架中的候选对象 | 需要验证的问题 |
|---|---|---|
| S1 Operations | Human / Agent / Software / Device 执行业务 | Agent 是否可作为自治 S1？一个 Agent 还是一个 Agent Team 更合理？ |
| S2 Coordination | Shared Context / World Model / Workflow / Coordination Agent | Shared World Model 是协调机制本身，还是协调信息基础？ |
| S3 Control | Resource / Policy / Runtime / Agent Portfolio / Operational Control | Runtime 与 Governance Enforcement 是否只是技术实现，而非组织功能？ |
| S3* Audit | Trace / Evidence / Observability / Independent Evaluation | Agent 时代 S3* 是否因机器可追溯性而显著增强？ |
| S4 Intelligence | Environment Sensing / Enterprise World Model / Prediction / FDE / Strategy Agent | World Model 到底服务 S4 还是横跨 S1–S5？ |
| S5 Policy | Purpose / Identity / Values / Ultimate Authority | 哪些 S5 功能长期必须由人或制度持有？AI 能否参与但不能拥有最终主权？ |

## 4. 当前最值得验证的四个问题

### RQ-VSM-01A｜VSM 是否真的“主体无关”

VSM 的理论对象是组织功能与复杂性调节，而不是某种具体岗位。因此它可能比大量以人类行为为前提的组织理论更容易扩展到非人类主体。

但需要验证：

- Beer 原始理论是否仍隐含大量社会、人类判断前提；
- “自治系统”是否可以直接等同于今天的 AI Agent；
- 机器自治与组织意义上的 autonomy 是否相同。

### RQ-VSM-01B｜Requisite Variety 在 AI 时代意味着什么

不能简单理解成“模型越强、参数越大越好”。

需要研究：组织应对复杂性的能力可能来自：

`Model Intelligence + Context + World Model + Capability + Human Judgment + Organizational Structure`

真正的问题是：

> 企业如何以可接受成本获得足够的“调节多样性”，而不是如何无限增加模型能力？

这可能与当前 Context Infrastructure、Capability Network 和 Agent Engineering 发生直接连接。

### RQ-VSM-01C｜递归性是否解释 Agent 组织的多层结构

候选结构：

`Agent → Agent Team → Digital Function → Department → Enterprise → Ecosystem`

如果每一层都需要某种 Operations / Coordination / Control / Intelligence / Policy 功能，VSM 可能提供比“多 Agent 拓扑图”更稳定的组织抽象。

需要寻找反例：

- 是否所有层级都需要完整 S1–S5；
- 是否会造成过度结构化；
- 临时 Agent Team 是否具备“viability”的必要条件。

### RQ-VSM-01D｜VSM 缺失哪些 AI 治理问题

即使 VSM 能解释控制、协调和适应，也不能默认它完整解决：

- 法律责任；
- Decision Rights 的合法来源；
- Agent 不能承担社会后果的责任真空；
- 价值冲突；
- 激励与政治；
- 数据权、隐私、合规。

因此当前倾向是：

> **VSM 更可能成为“组织可行性与协调”的骨架，而不是完整的 AI 时代管理理论。**

它需要与 Agency Theory、Decision Rights、Organization Design、Organizational Learning 等共同使用。

## 5. 近期学术与实践信号

> 本节只记录已找到的信号，不据此声称“VSM 已成为 AI 组织理论主流”。当前更谨慎的表述是：2025–2026 已出现一组将 VSM 与 AI/LLM/Agent 重新连接的研究与实验，值得持续观察。

### 5.1 Jose Perez Rios｜2025

**The Viable System Model and the Taxonomy of Organizational Pathologies in the Age of Artificial Intelligence (AI)**

- Journal: *Systems* 13(9), 749
- Published: 2025-08-29
- 价值：直接把 VSM 用于 AI 时代的组织诊断与病理分析。
- 来源：https://www.mdpi.com/2079-8954/13/9/749

### 5.2 Richard Sean O'Rourke｜2026

**The LLM as variety transducer: Ashby's intelligence-amplifier architecture and Beer's viable system model as a diagnostic and predictive framework**

- Journal: *Kybernetes*
- Published online: 2026-07-21
- 价值：尝试用 Ashby + Beer 解释 Human–LLM coupled system，并认为人的元系统功能对当前 LLM 系统可行性仍重要。
- DOI: https://doi.org/10.1108/K-03-2026-0482
- 注意：这是概念论文，不应直接当成已经成熟验证的组织理论。

### 5.3 Cognitive AI Agents × Industry 5.0｜2026

**Cognitive AI Agents in Life Cycle Management of Industry 5.0 Organizations: A Conceptual Framework**

- 价值：以 VSM 作为 formal blueprint，将 Policy、Intelligence、Control、Audit、Coordination、Operation 与 Cognitive AI Agent 类型进行映射。
- 来源：https://www.sciencedirect.com/science/article/pii/S2212827126007006
- 注意：当前属于概念性框架，后续需要看实证验证。

### 5.4 Raul Espejo｜VSM 向新组织形态延伸

**The enterprise complexity model: An extension of the viable system model for emerging organizational forms**

- First published: 2020
- 价值：不是 AI 论文，但把 VSM 延伸到新兴组织形态、自组织、复杂环境和数字技术支持的协作网络，是连接 Beer 与今天 AI 组织问题的重要桥梁。
- DOI: https://doi.org/10.1002/sres.2735

### 5.5 实验型实现信号（非核心理论证据）

已有开发者尝试把 VSM 用作单 Agent 或 Multi-Agent 的运行架构。这类项目可以用于观察工程映射，但不能与同行评审理论证据等同。

示例：

- Viable System Generator：https://www.agent.nhilbert.de/
- Multi-Agent Code Review using VSM：https://www.eoinhurrell.com/posts/20250306-viable-systems-ai/

## 8. 当前临时判断

**H-VSM-001｜Exploring**

> VSM 值得作为 Enterprise Intelligence 的候选组织元模型之一进行压力测试，但当前没有足够证据把它直接定义成“LLM 时代组织理论的答案”。

**H-VSM-002｜Exploring**

> VSM 的最大潜力可能不是给 Agent 系统重新命名 S1–S5，而是提供“自治智能单元如何通过协调、控制、环境智能和身份政策形成可持续整体”的长期组织问题框架。

**H-VSM-003｜Exploring**

> Enterprise World Model 可能横跨 VSM 多个系统，而不是简单对应 S4；它可能同时支撑 S1 的业务事实、S2 的共享语义、S3 的控制信息和 S4 的环境理解。
