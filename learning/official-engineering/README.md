# Official Engineering Learning

这是官方工程知识学习流的最小工作区。它服务于持续理解和复用，不构成新的 Research Problem 或第二套 Research State。

- 协议：[ops/official-engineering-learning.md](../../ops/official-engineering-learning.md)
- 候选入口：[source-queue.md](source-queue.md)
- 人工确认后的知识卡：[notes/](notes/)

`source-queue.md` 是本流的唯一候选队列。发现、AI 分析和推荐可以自动发生；选择、阅读、人类理解和应用必须由研究者确认。与已有论文体系的关系是“复用问题驱动和停止条件”，不是把官方资料并入 `research/reading-list.md`。
